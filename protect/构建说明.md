# PDF 流式打印器 — Tauri 版 构建指南

## 环境要求

| 工具 | 版本 | 安装 |
|------|------|------|
| Rust | ≥ 1.75 | `winget install Rustlang.Rustup` 或 https://rustup.rs |
| Microsoft Visual C++ Build Tools | 2019+ | `winget install Microsoft.VisualStudio.2022.BuildTools` |
| WebView2 | 预装 | Win10/11 已内置，Win7 需手动安装 |
| Tauri CLI | 2.x | `cargo install tauri-cli --version "^2"` |

## 项目结构

```
04-new-protect/
├── src/                       # Web 前端
```

## 构建步骤

### 1. 安装 Rust 工具链

```bash
# 安装 Rust
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
# 或 Windows: https://rustup.rs

# 安装 Tauri CLI
cargo install tauri-cli --version "^2"
```

### 2. 获取 PDFium 动态库

pdfium crate 需要 `pdfium.dll`。两种方式：

**方式 A — 手动放置**（推荐）：
从 https://github.com/bblanchon/pdfium-binaries 下载 Windows x64 版本，
将 `pdfium.dll` 放到以下任一位置：
- 项目根目录 `04-new-protect/src-tauri/`
- 系统 PATH 目录
- 与最终 exe 同级目录

**方式 B — 环境变量**：
设置 `PDFIUM_DYNAMIC_LIBRARY_PATH` 指向 `pdfium.dll` 所在目录。

### 3. 构建 exe

```bash
cd 04-new-protect
cargo tauri build
```

首次构建会下载 Rust 依赖（约 5-10 分钟），后续构建增量编译。

输出：
- `src-tauri/target/release/pdf-printer.exe` — 独立 exe
- `src-tauri/target/release/bundle/msi/` — MSI 安装包

### 4. 开发调试

```bash
# 终端1: 启动前端开发服务器
cd src && python -m http.server 1420

# 终端2: 启动 Tauri 开发模式
cargo tauri dev
```

或直接构建测试：
```bash
cargo tauri build --debug
```

## 常见问题

**Q: 报错 `pdfium.dll not found`**
A: 下载 pdfium.dll 放到 `src-tauri/` 目录下。确保是 Windows x64 版本。

**Q: 构建报错 `link.exe not found`**
A: 安装 Visual Studio Build Tools，确保安装了 "C++ 桌面开发" 工作负载。

**Q: 如何减小 exe 体积**
A: 使用 UPX 压缩: `cargo install upx`，然后在 Cargo.toml 中添加 `strip = true` 和 `opt-level = "z"`。

**Q: 可以用 `cargo build` 代替 `cargo tauri build` 吗**
A: 可以，但 `cargo build` 只编译 Rust 部分，不会打包前端文件。`cargo tauri build` 会一并处理。
